|------|------|

## 二、核心功能模块

### 1. AI 智能排座 🧠
- 概率引擎综合分析学生多维数据
- 一键生成最优座位方案
- 支持约束条件：性别均衡、特殊需求适配、黑白名单、社交偏好
- 排座结果可手动微调

### 2. 性格测评系统 📊
- 35 道科学测评题
- 覆盖维度：MBTI 人格、学习风格、社交类型、兴趣爱好、特殊需求
- 约 10-15 分钟完成
- 自动保存进度，支持断点续答

### 3. 学生画像 👤
- 自动计算综合评分
- 生成 MBTI 类型、学习风格、社交类型标签
- 可视化雷达图报告
- 多维度数据交叉分析

### 4. 可视化排座编辑 🎨
- 教室座位网格可视化
- 拖拽手动换座
- 热力图分析（成绩分布、性别比例等）
- 撤销/重做操作
- 禁用/启用座位

### 5. 申诉管理 🔄
- 学生提交换座申请
- AI 自动分析合理性并给出建议
- 教师一键批准/驳回
- 申诉历史可追溯

### 6. 数据导出 📤
- CSV 基础/完整表格
- PNG 座位图截图
- PDF 完整报告

### 7. 其他功能
- 深色/浅色主题切换
- 移动端响应式适配
- 微信/QQ OAuth 登录（可选）
- 短信/邮件验证码（可选）

## 三、使用流程

```
步骤 1：创建班级
  教师注册登录 → 创建班级 → 配置教室行列布局 → 生成邀请码

步骤 2：学生测评
  学生用邀请码注册 → 完成 35 道性格测评（约 15 分钟）

步骤 3：AI 排座
  教师点击「AI 智能排座」→ 系统自动生成方案 → 查看热力图分析

步骤 4：发布调整
  教师审核 → 手动微调 → 发布座位 → 学生可提交申诉
```

## 四、部署方式

### 方式一：Vercel + Supabase（推荐）
- 免费云部署
- 无需服务器
- 3 分钟完成
- 标签：免费、云端、零运维

### 方式二：本地一键启动
- 双击即用
- 无需任何配置
- 内置 SQLite 数据库
- 标签：零配置、本地、SQLite

### 方式三：Docker 部署
- 容器化部署
- 适合有经验的用户
- 标签：Docker、容器化、MySQL

## 六、设计规范

### 配色方案

| 用途 | 色值 | 说明 |
|------|------|------|
| 背景色 | `#0A0A0F` | 深色主题主背景 |
| 卡片背景 | `rgba(255,255,255,0.03)` | 半透明玻璃质感 |
| 主色 | `#6366F1` | 靛蓝（Indigo） |
| 主色浅 | `#818CF8` | 用于渐变和高亮 |
| 辅色 | `#06B6D4` | 青色（Cyan） |
| 辅色浅 | `#22D3EE` | 用于渐变 |
| 强调色 | `#EC4899` | 粉色，用于特殊高亮 |
| 成功色 | `#10B981` | 绿色，表示在线/成功 |
| 文字色 | `#F1F5F9` | 主文字 |
| 辅助文字 | `#64748B` | 说明文字 |
| 边框色 | `rgba(255,255,255,0.06)` | 微妙边框 |

### 渐变

- 主渐变：`linear-gradient(135deg, #6366F1, #06B6D4)`
- 文字渐变：`linear-gradient(135deg, #818CF8, #22D3EE, #EC4899)`
- 背景光晕：`radial-gradient(circle, rgba(99,102,241,0.08), transparent)`

### 字体

- 英文：Inter（Google Fonts）
- 中文：Noto Sans SC（Google Fonts）
- 标题字重：800-900
- 正文字重：400-500

### 圆角

- 卡片：20px
- 按钮：12px
- 小元素：8px
- 胶囊标签：100px

### 阴影

- 卡片悬停：`0 30px 60px rgba(0,0,0,0.4)`
- 主色发光：`0 4px 20px rgba(99,102,241,0.4)`
