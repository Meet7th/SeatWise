什么是 SeatWise？

SeatWise 是一个现代化的教室座位编排系统，支持手动拖拽和 AI 智能排列。教师可以根据学生需求自动生成最优座位方案，支持多种排列策略和数据导出。

核心特性

功能说明
AI 智能排列根据成绩、身高、视力等因素自动编排座位
手动拖拽直观的拖拽界面，灵活调整座位安排
数据分析成绩与座位位置的相关性分析报告
多格式导出支持 Word、图片、Markdown 格式导出
多班级管理同时管理多个班级和教室布局

快速开始

选择最适合你的方式，在几分钟内开始使用 SeatWise

💡
自动化脚本会帮你完成所有操作：创建数据库、部署前后端、初始化数据。只需准备 3 个 Token。
获取所需的 Token
你需要准备 3 个 Token：
• Supabase Token — 创建数据库
• Vercel Token — 部署应用
• GitHub Token — Fork 代码仓库

查看详细 Token 获取教程 →
运行部署脚本
Linux / macOS / Git Bash：
bash 
curl -fsSL https://raw.githubusercontent.com/Meet7th/SeatWise/main/setup.sh | bash
Windows PowerShell：
powershell 
git clone https://github.com/Meet7th/SeatWise.git
cd SeatWise
.\setup.bat
等待部署完成
脚本会自动完成所有操作，最后输出前端和后端的访问地址。整个过程约 5-10 分钟。

环境要求

工具版本安装
Node.js18+nodejs.org
pnpm9+npm install -g pnpm@9
Git最新git-scm.com

安装步骤

bash 
# 1. 克隆仓库
git clone https://github.com/Meet7th/SeatWise.git
cd SeatWise

# 2. 安装依赖
corepack enable

# 3. 配置环境变量
cp apps/server/.env.example apps/server/.env

# 4. 初始化数据库
pnpm --filter @seatwise/server exec prisma db push

# 5. 启动开发服务器
pnpm dev

部署日志

Token 获取详细教程

Supabase Token

注册并登录 Supabase
打开 supabase.com，点击 "Start your project"，用 GitHub 账号登录
进入 Token 页面
登录后 → 点击左下角头像 → Account Settings → 左侧 Access Tokens
生成 Token
点击 "Generate new token" → 输入名称如 seatwise-deploy → 点击 "Generate token" → 立即复制保存

Vercel Token

注册并登录 Vercel
打开 vercel.com，用 GitHub 账号登录
进入 Token 页面
点击右上角头像 → Settings → 左侧 Tokens
创建 Token
点击 "Create" → 输入名称如 seatwise-deploy → 点击 "Create Token" → 立即复制保存

GitHub Token

⚠️
GitHub Token 需要 Fine-grained token 类型，并授予 Contents (Read and write) 权限。
进入 Token 设置
登录 GitHub → 右上角头像 → Settings → 底部 Developer settings → Personal access tokens → Fine-grained tokens
配置权限并生成
点击 "Generate new token" → 输入名称 → "Repository access" 选 All repositories → "Permissions" 找到 Contents 选 Read and write → 点击 "Generate token"
保存 Token
⚠️ Token 只会显示一次！立即复制保存。如果丢失需要重新生成。

Vercel 部署

零成本、零服务器，适合个人使用和小规模部署

✅
推荐方案 — Vercel 免费额度支持每月 100GB 流量，自动 HTTPS，全球 CDN。

前置准备

服务用途费用
SupabasePostgreSQL 数据库免费 500MB
Vercel前后端托管免费 100GB/月
GitHub代码托管免费

部署步骤

Step 1: 创建数据库

在 Supabase 创建一个免费项目，获取数据库连接字符串。

🗄️ 创建 Supabase 项目

创建完成后进入 Settings → Database → Connection string → URI，复制连接字符串。

Step 2: 部署后端

点击按钮，将 root-directory 设为 apps/server，填入环境变量：

env 
DATABASE_URL=你的Supabase连接字符串
JWT_SECRET=任意随机字符串
JWT_REFRESH_SECRET=另一个随机字符串
FRONTEND_URL=前端部署后的地址（部署后填）
▲ 部署后端到 Vercel

Step 3: 部署前端

将 root-directory 设为 apps/web，填入后端地址：

env 
VITE_API_BASE_URL=https://你的后端域名.vercel.app
▲ 部署前端到 Vercel

Step 4: 初始化数据库

访问后端的初始化接口：

url 
https://你的后端域名.vercel.app/api/init

看到 "Database initialized successfully" 即完成。

使用 Vercel CLI 部署

bash 
npm i -g vercel

git clone https://github.com/Meet7th/SeatWise.git
cd SeatWise

# 部署后端
cd apps/server
vercel --prod

# 部署前端
cd ../web
vercel --prod

本地开发

环境要求

工具版本安装
Node.js18+nodejs.org
pnpm9+npm install -g pnpm@9
Git最新git-scm.com

安装步骤

bash 
# 克隆仓库
git clone https://github.com/Meet7th/SeatWise.git
cd SeatWise

# 安装依赖
corepack enable
pnpm install

# 配置环境变量
cp apps/server/.env.example apps/server/.env

# 初始化数据库（默认 SQLite，无需额外配置）
pnpm --filter @seatwise/server exec prisma db push

# 启动开发服务器
pnpm dev

环境变量配置

.env 
# 数据库（SQLite 默认，无需修改）
DATABASE_URL="file:./seatwise.db"

# JWT 密钥（请修改为随机字符串）
JWT_SECRET="your-secret-here"
JWT_REFRESH_SECRET="your-refresh-secret-here"

# 前端地址（开发环境默认）
FRONTEND_URL="http://localhost:5173"

常见问题

使用前必读的常见问题解答

部署问题

Vercel 部署失败怎么办？

常见原因 1：TypeScript 编译错误
已内置跳过类型检查，通常不会出现。如仍有错误，检查环境变量配置。

常见原因 2：数据库连接失败
确保 Supabase 连接字符串格式正确，密码中没有特殊字符。推荐使用 "Transaction" 模式连接字符串。

常见原因 3：依赖安装失败
确保 packageManager 字段已设置，Vercel 会自动启用 corepack。

Docker 容器启动失败？

检查日志： docker compose logs -f

端口占用： 修改 docker-compose.yml 中的端口映射

内存不足： 确保服务器至少 2GB 可用内存

部署脚本 (setup.sh) 运行失败？

curl SSL 错误： 先克隆仓库再运行脚本：

bash 
git clone https://github.com/Meet7th/SeatWise.git
cd SeatWise
bash setup.sh

Token 无效： 确保 Token 没有过期，权限配置正确。

使用问题

AI 排列结果不理想？

1. 调整学生数据（成绩、身高、视力等）使数据更准确

2. 尝试不同的排列策略（成绩均衡、身高分层等）

3. 使用 AI 排列后，手动微调不满意的座位

数据如何备份？

SQLite： 复制 apps/server/seatwise.db 文件

Supabase： Dashboard → Settings → Database → Backups

手动导出： 使用应用内的 JSON 导出功能

如何更新到最新版本？

Vercel： Fork 仓库中同步上游更新，Vercel 自动重新部署

Docker： docker compose pull && docker compose up -d

本地： git pull && pnpm install && pnpm dev

故障排除

遇到问题？在这里找到解决方案

错误代码速查

错误原因解决方案
ECONNREFUSED数据库连接被拒绝检查数据库是否启动，连接字符串是否正确
P1001Prisma 无法连接检查 DATABASE_URL 环境变量
TS2307找不到模块运行 pnpm install

排查流程

1. 应用无法启动

bash 
# 检查版本
node --version  # 需要 18+
pnpm --version  # 需要 9+

# 清除缓存重装
rm -rf node_modules pnpm-lock.yaml
pnpm install

# 检查端口占用
lsof -i :5173
lsof -i :3000

2. 数据库问题

bash 
# 检查连接
pnpm --filter @seatwise/server exec prisma db push

# 重置数据库（⚠️ 会丢失数据）
pnpm --filter @seatwise/server exec prisma migrate reset

# 可视化管理
pnpm --filter @seatwise/server exec prisma studio
