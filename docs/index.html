常见问题

FAQ

需要会编程才能使用吗？

不需要。推荐使用 Vercel 一键部署按钮或本地 `pnpm start`，全程无需编写代码。

数据安全吗？

密码使用 bcrypt 加密存储，接口使用 JWT 认证，本地部署完全离线运行，保障数据安全。

可以离线使用吗？

可以。本地部署无需联网，OAuth 登录和短信验证功能除外。

支持哪些浏览器？

支持 Chrome、Edge、Firefox、Safari 等主流浏览器，以及移动端浏览器。

如何备份数据？

SQLite 备份 .db 文件即可；MySQL 使用 mysqldump；Docker 备份 docker-data/ 目录。
